# Dev Wisp Android

Android 客户端使用 Kotlin 和原生 Android View 绘制，不通过 WebView 加载网页。聊天输入框使用 Android 原生 `EditText`，键盘由系统输入法提供。

首次启动时填写电脑网页地址，例如 `http://192.168.15.22:26546`，以及服务启动时显示的配对码。APP 会直接请求网页服务转发的 `/api/v1/pair` 接口；26546 网页端口不提供 `/health` 路径。

Dev Wisp 保持原 Android application ID：`com.sevencnup.codexremote`，显示名称与源码 namespace 可以随品牌更新。使用相同签名安装即可覆盖旧版，并继续使用原来的连接配置、主题和聊天选择，无需重新配对。

## 构建

需要 Java 17、Android SDK（platform 35 和 build-tools 35.0.0）：

```bash
cd android
ANDROID_HOME=/path/to/android-sdk ./gradlew assembleDebug
```

APK 输出在 `app/build/outputs/apk/debug/devwisp-android-<版本号>-debug.apk`。发布安装包应配置正式签名后再构建 release 版本。

## 本机内网更新

设置页“检查更新”使用当前保存的电脑连接地址及配对凭据，通过当前配置的网页服务端口（默认 `26546`）访问 `/api/v1/android/update`，不会连接 GitHub。服务会从项目根目录 `artifacts/` 选择版本最高的 `devwisp-android-<版本号>-debug.apk`；后续打包后须将新文件以这个名字单独复制到该目录，历史包不要覆盖。更新下载在 App 内显示进度、百分比和大小，可取消或收起；收起后再次点击“检查更新”可恢复进度。下载任务可在后台继续，不显示系统下载通知；完成后校验安装包，再打开 Android 系统安装界面。首次使用时可能需要允许 Dev Wisp 安装未知应用；安装仍由用户在系统界面确认。

为 App 发布可检测的新包时，必须同时递增 `versionName` 和 `versionCode`；同一目标版本的内部测试包递增 `-dev.N`。同版本重打包不会提示更新，文件名附加时间戳的归档也不会进入更新清单。完成后核对更新源选出的版本、文件大小和 SHA-256，再提供下载入口。

## 内置浏览器

浏览器使用独立页面，地址栏位于底部浏览按钮上方；网页左下角的小按钮可将这两排控件一起收起/展开，收起后网页填满系统安全区内的可用空间。输入法出现时按键盘高度适配，不再受聊天输入框限制。底栏星形按钮可收藏或取消收藏当前网页，收藏夹和浏览历史仅保存在这台手机上。点击底部网址即可在地址栏直接修改网址或输入搜索词，使用键盘“前往”或右侧箭头打开，叉号取消编辑。返回键先退出地址编辑或展开已隐藏的控件，再后退网页；无历史时收起整个浏览器到聊天页左下角地球图标，点击恢复原网页，长按切换网页。收起/展开控件以及收起/恢复整个浏览器均保留同一网页实例及其滚动、表单和浏览历史，显式关闭网页时才释放；关闭全部网页后，控件恢复默认展开。

## 消息重新发送与 Claude 审批

已确认发送的用户消息下方提供刷新图标，可重新发送该消息及原有图片、文档，不会清空当前草稿。回复进行中或聊天暂停时，重新发送的消息遵循普通排队规则。发送状态不明的消息仍使用消息下方的重试入口确认，避免重复提交。

电脑端 Claude 产生真实权限请求时，当前聊天会显示审批卡片，展示工具、命令或文件、目录和原因，可以允许一次或拒绝。App 会在重连、回到前台时同步尚未处理的审批，并同步清除电脑端已处理的请求；请求的产生由电脑端 Claude 的权限配置决定。

## 聊天翻译

在设置页“聊天翻译”中启用后，Android 通过当前电脑的翻译接口预览中文草稿的英文译文；发送、定时发送和编辑排队消息时使用该译文，并保留原文供聊天记录切换。AI 英文回复完成后可显示中文译文。翻译模型、地址和密钥使用网页端已保存的电脑配置，手机只保存引擎、配置选择及显示偏好；模型配置如有修改，可在 App 中刷新。网页版当前选择只保存在浏览器中，手机可在“使用的配置”中直接选择电脑已保存的任一可用模型。

## DeepSeek 模式

聊天顶部显示当前模式以外的两个引擎图标，点按即可直接切换；例如 Codex 对话显示 Claude Code 和 DeepSeek。侧栏提供三种引擎的独立筛选。App 会记住每台电脑的模式与选中聊天，DeepSeek 的草稿和发送偏好独立保存。

DeepSeek 使用当前连接电脑在网页端保存的 API 地址、协议、模型和密钥，手机无需重复配置密钥；未配置时会显示提示。输入框设置可选择默认或 DeepSeek 模型、Agent、思考等级及五种权限模式，支持普通发送、附件、定时、排队编辑、重发和中断后继续。第三方模型选择“电脑端默认模型”，思考选项跟随电脑返回的模型能力。

DeepSeek Harness 的选择题沿用 Codex 的快速选择样式，支持多选、自定义回答和计划审核。成功提交后，聊天中显示对应的用户回答；连接较旧的电脑端时，App 会在本机保留已确认的回答，电脑端返回同一条消息后自动去重。

Agent 支持 Standard、PTC、Minimal、Creator；已有聊天沿用电脑端绑定的 Agent，切换 Agent 需新建聊天。Minimal 不提供计划模式。DeepSeek 的权限审批、单选／多选提问、自定义回答和计划审核显示在对应聊天中，重新连接或回到前台后会恢复待处理请求。使用 DeepSeek 需电脑服务支持该模式，旧版电脑仍可使用原有模式。
