# 协同创建页面精简

## 目标与分类

依据用户截图和“越简单越好”的要求，将默认创建流程收敛为选择两位助手、输入需求、开始协同。每位助手用一个选择框直接选择新建引擎或已有单聊，取消来源/搜索/会话的多层配置。任务名默认从需求生成；自定义名称、项目目录、模型和轮数保留在默认折叠的更多设置中。保留共享左右侧栏、原生历史、失败草稿及后端接管保护。

属于 Fix / PATCH：用户能完成的任务不变，减少配置步骤和页面负担。目标版本 `0.138.3-dev.1`，若有并行版本提交则按最终基线递增补丁版本。无新增依赖、不改后端调度、不推送。

## 实施步骤

1. 核对页面、已有单聊接管约束及设计上下文，使用 distill/frontend-design 原则明确默认必需内容。
2. 合并每位成员的选择，移除重复搜索、角色说明和长提示；将次要配置折叠，自动生成默认任务标题，维持幂等重试和草稿。
3. 精简相关样式并验证窄屏、深浅主题、键盘操作及高级设置可达性。
4. 完成类型检查、生产构建与隔离浏览器验证，重点检查默认流程、混合成员、重复/跨目录防护、自动命名、自定义设置及失败重试；不调用真实模型、不重启用户服务。
5. 更新简要版本记录及说明，清理一次性脚本/调试进程，仅本地提交本次改动。

## 实施与验证结果

- 默认只显示实现者/审查者两个选择框、一个需求输入框及开始按钮。新建的三种引擎与已有单聊放在各自成员选择框中；删除独立来源切换、常驻搜索框、重复上下文与长说明，以及顶部大标题。
- 任务名从需求自动生成，合并空白、限制100个Unicode字符，避免切断表情符号。自定义名称、目录、每位成员模型与轮数保留在默认折叠的更多设置中；既有单聊仍沿用其目录和上下文。目录加载失败时自动展开设置并提示填写。
- 保留重复/跨项目选择防护、逐成员图标、失败草稿和幂等恢复，包括创建成功但响应丢失、成员归属列表已刷新的情形。没有改变后端接口或调度规则，无新增依赖。
- TypeScript项目检查、Vite生产构建通过，保留既有大包体积提示。隔离HTTP/WebSocket浏览器检查通过：默认仅两个可见选择框和一个文本区；双已有/双新建/新旧混合；自动及自定义名称；高级目录/模型/轮数设置；键盘展开折叠；409后草稿、同编号重试、响应丢失恢复；Unicode标题；目录加载失败后手动恢复。
- 已检查320/390/768/1440px及深浅主题截图，默认手机页面的开始按钮在首屏可见，无横向溢出或浏览器运行异常。截图保留在忽略的 `artifacts/simple-team-*.png`。
- 未调用真实模型、未做实体设备验证、未重启当前服务或部署。本轮浏览器临时服务随脚本关闭，清理一次性脚本和构建日志后仅本地提交，不推送。
