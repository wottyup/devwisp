# Android 图标比例、顶部模式切换与思考等级显示修复

## 问题与分类

DeepSeek 官方鲸鱼图标的原始画布为 `56.203 × 41.36`，Android 资源的固有尺寸为 `24dp × 24dp`。两个坐标轴缩放比例不同，使鲸鱼被纵向拉长。

用户补充：顶部图标应是模式切换目标，显示当前模式以外的两个引擎，并可直接点击切换。例如 Codex 模式显示 Claude 与 DeepSeek。

用户再次补充：思考等级 `xhigh` 的英文应直接显示参数名称，统一移除 `Extra High` / `Very high` 的替代文案；发送给模型的参数保持 `xhigh`。

属于 Fix / PATCH：修复既有图标显示比例、模式切换和思考等级文案，用户可执行的任务不变。图标验证包为 `0.129.1-dev.1` / `versionCode 469`，模式切换验证包为 `0.129.1-dev.2` / `versionCode 470`，最终包为 `0.129.1-dev.3` / `versionCode 471`，历史包保留。

## 实施步骤

1. 对照官方 SVG、Android VectorDrawable 和图标容器，确认变形来源。
2. 保持鲸鱼路径不变，使用正方形 viewport，并通过分组位移将原图垂直居中；确保横纵等比缩放。
3. 顶部使用两个独立图标按钮，按固定引擎顺序排除当前模式，各按钮直接切换到对应模式；切换或恢复聊天后刷新目标图标，保持草稿和聊天选择的现有行为。
4. 统一思考选项、输入框摘要、排队消息和回复元数据中的 `xhigh` 英文显示，保留中文“极高”以及原始请求参数。
5. 构建 Android APK，核对编译资源、版本及签名；使用适用的现有单元测试，不添加实现镜像式测试。
6. 保留历史 APK，将新包单独归档，覆盖安装到本次已授权的 `10.126.126.2:5555`，核对配置保留、真机图标比例、三种模式各显示另外两个切换目标，以及 `xhigh` 显示。
7. 记录验证结果和版本摘要，清理临时截图、UI 转储及 ADB 调试连接，完成本地提交，不推送。
