# Android DeepSeek 可折叠运行详情

## 需求与数据核对

在 DeepSeek 回复底部提供与网页版相同的“运行详情”折叠入口，展示本轮 Token 等信息，沿用 App 自己的主题与消息布局。

网页参考：`src/components/HarnessTurnDetails.tsx`、`src/lib/harnessTelemetry.ts`、`src/lib/devwispClient.ts`。服务端将 `harnessTelemetry` 存入本轮 items，并通过 `deepseek/turn/telemetry` 通知更新。Android 当前未解析此信息，落入通用操作记录分支。

本次只接入网页版“运行详情”包含的指标：运行状态、进程复用/重建状态、主 Agent 本轮已报告的输入/输出/缓存/思考/总 Token、部分请求未报告用量提示、最近请求上下文与容量。模型、思考等级继续独立显示。子 Agent 用量不合并进主 Agent，思考 Token 不重复计入输出；不估算服务端未提供的指标。不额外改动网页端的思考内容或子 Agent 展示。

## 分类与版本

New Features / MINOR：App 首次支持查看每轮 DeepSeek 运行与用量数据；折叠是该新能力的展示方式。Android `0.131.0-dev.1`、versionCode `478`，保留原包名及历史安装包。

## 实施步骤

1. 增加独立 Kotlin 指标解析，按网页校验阶段和非负安全整数，仅取当前轮最新 telemetry，不填补缺失值。
2. 从通用操作记录排除 telemetry，在每轮最后一条 AI 回复的底部加入默认收起的“运行详情”；无正文但有有效指标的轮次也能展示。点击区域限制在箭头和文字，展开状态按连接/聊天/轮次保存，刷新后保留状态。
3. 接入现有节流的历史刷新，保证实时通知、完成、重连及本机缓存一致；展开/收起暂停自动跟随，取消旧滚动回调，保留阅读位置。
4. 补齐中英文文案，适配窄屏、长数字及 App 主题。用真实服务协议夹具回归缺失/非法/零值、最新记录、计数隔离及上下文百分比，运行 Android 测试和构建。
5. 校验签名、版本并独占归档 APK，按已有授权更新手机原应用；仅检查安装与启动，不操作真实聊天、不调用真实模型。记录实际验证范围，清理本次临时文件，本地提交，不推送。
