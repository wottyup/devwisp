# Android 终端粘贴与语言修复

## 需求与分类

在顶部终端的“复制到输入框”一排新增“粘贴到终端”，将系统剪贴板文字送入当前终端；“键盘”和空白画面的“等待终端输出…”跟随 App 语言。沿用自己的主题与原有终端连接、AI 接管和手动输入规则。

分类 Fix / PATCH：补齐已有终端输入的快捷入口及本地化，不改变终端可执行的任务。目标 Android `0.130.1-dev.1`、versionCode `477`，保留历史 APK。

## 实施步骤

1. 在现有复制操作旁加入粘贴按钮，与键盘和快捷键使用相同的连接就绪状态；处理空剪贴板、读取失败和发送失败，不记录剪贴板内容。
2. 粘贴沿用终端输入通道，不额外附加回车；识别远端 bracketed paste 模式，保持多行粘贴与终端模式一致。按钮行适应英文和较大字体，键盘入口仍在右侧。
3. 补齐键盘、粘贴及相关反馈的英文文案；将空白等待文案作为渲染参数传入，仅翻译 UI 占位符，不翻译真实终端输出。
4. 对终端输出边界和粘贴模式增加必要回归，运行 Android 单元测试和构建，校验并独占归档新 APK。
5. 按现有授权更新手机上的原应用，仅做安装和启动检查，不粘贴内容或向用户真实终端发送命令。清理本次临时文件，记录实际验证范围，本地提交，不推送。

- 在“复制到输入框”旁加入“粘贴到终端”，直接读取系统剪贴板纯文本，经原输入 WebSocket 发送；空剪贴板、无法读取和发送失败均有本地化反馈。连接未就绪时与键盘及快捷键一起禁用，关闭终端时清除按钮引用。
