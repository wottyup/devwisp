# Android 浏览器收藏、地址编辑与收起入口

## 需求与分类

收藏夹来自手机本地的 `browser_bookmarks`，原有添加/取消收藏入口位于“网页工具”，并非外部同步的书签。用户希望在底栏直接收藏，在顶部地址栏直接修改网址，并将左下角的收起入口从长文字按钮缩成地球图标。

本次属于 Fix / PATCH：收藏、地址导航与浏览器恢复均为既有能力，调整入口和编辑方式以改善操作体验。目标 Android 版本 `0.131.2-dev.1`，`versionCode 481`。

## 实施步骤

1. 在底栏增加独立收藏图标，区分未收藏/已收藏，复用现有本地书签模型与持久化逻辑；工具菜单和收藏夹删除/清空同步更新图标，空白或无效页面不可收藏。工具栏缩窄时仍保留可触达的按钮。
2. 点击顶部网址后，在同一地址栏内显示编辑框、前往和取消操作；键盘“前往”共用现有 URL/搜索解析。网页加载进度、标题和重定向刷新不得覆盖输入草稿；切换、关闭或收起页面时结束编辑并正确关闭输入法。
3. 左下角恢复入口仅显示地球图标，保持 44dp 触摸区域、点击恢复和长按网页列表。页面数量和标题仅用于无障碍描述，不继续占用可见文字宽度。复用现有主题图标与矢量资源风格。
4. 补齐英文文案、版本摘要和说明，执行现有 Android 单元测试并构建 APK；核对包名、版本和签名，独占新建归档至 artifacts，验证更新源选中该版本。清理临时日志，仅本地提交，不推送；不安装另一应用、不提前覆盖手机、不操作真实聊天。
