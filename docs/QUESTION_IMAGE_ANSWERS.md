# 选择题其他回答支持图片

## 范围与顺序

1. 复用现有受鉴权聊天图片存储、大小与数量限制，提供回答图片上传接口。
2. 共用粘贴处理和附件展示，支持多图、删除、图片-only 回答、上传中禁用提交；不影响普通文本粘贴与输入法。
3. 普通快速选择沿用聊天原生图片附件；填入主输入框时一同带入图片。
4. Codex/DeepSeek 工具提问的协议只接受文本答案，因此附上服务器托管图片路径和读取提示，不伪造协议中的图片字段。
5. 校验选择切换后不误发隐藏图片、上传失败可重试、多问题附件数量上限；运行回归测试与构建。
6. 本地提交，不自动推送或重启服务。

## 分类

MINOR：新增选择题中提交图片的能力，版本 0.138.0-dev.1。

## 验证

- TypeScript 与 Vite 构建通过。
- 9 项 Node 测试覆盖图片剪贴板提取、读取、格式/数量/大小限制、文本引用及现有输入法/草稿行为。
- 8 项 Python 测试覆盖上传配对鉴权、托管路径、非法数据、存储配额、Codex 自定义回答及 DeepSeek 问题应答。
- 未调用付费模型做图片识别端到端测试；工具提问仍为文本协议，由 AI 使用图片读取工具访问引用，受当前引擎的读文件权限和视觉能力约束。
- 普通快速选择仍发送原生图片附件。密码类回答不启用图片粘贴。
- 没有重启用户当前后端；工具问题上传接口需重启后端后生效。
