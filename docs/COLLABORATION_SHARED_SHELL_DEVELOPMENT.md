# 协同与单聊共享工作台开发文档

## 目标与分类

按本轮要求让单聊与协同复用同一个左右侧栏。左侧统一呈现普通聊天和协同会话；协同标题按成员数量显示模型所属引擎图标，同引擎成员不去重。右侧保留文件树、预览及终端，并跟随所选会话的项目目录。

这是现有协同能力的布局与导航优化，属于 Fix / PATCH，目标版本 `0.137.4-dev.1`（以并行提交完成后的 `0.137.3-dev.1` 为版本基线）。不改协同任务调度、成员数量配置或后端权限机制。

## 实施步骤

1. 检查现有工作台、会话分组/搜索/引擎过滤、文件操作及窄屏侧栏行为，确认共享外壳接入点。
2. 移除协同的独立外壳，将协同内容嵌入现有工作台；保留单聊和协同草稿、成员查看与审批、暂停/继续等行为。
3. 把协同会话加入统一历史列表并实现搜索、任一参与引擎筛选、选中和日期分组；标题显示每位参与成员的引擎图标及可访问模型说明，避免将任务编号发给原生会话接口。
4. 让共享文件树跟随协同目录；验证预览、插入路径和终端操作。复用设置、用量统计、引擎状态、折叠与拖拽，处理手机侧栏开关。
5. 更新 README、版本记录与本文件；完成 TypeScript、生产构建及有针对性的导航/浏览器检查，记录未验证范围。
6. 清理本轮临时脚本和调试进程，仅本地提交本任务改动，不推送，不包含同时进行的用量明细修改。

## 验收重点

- 整个界面始终只有一套左右侧栏；两种模式可互相打开两类会话，设置和用量入口一致。
- 协同标题/列表图标逐成员显示；相同引擎的两位成员显示两个图标，图标说明含角色和模型。
- 普通会话的多选、置顶、删除、并发打开不误操作协同任务；成员会话仍受任务管理。
- 切换模式不丢单聊/新任务草稿，不停止后台任务；手机可打开、关闭共享侧栏且无水平溢出。
- 文件树跟随协同项目，路径/文档插入到协同要求，终端不意外操作隐藏单聊。
- 使用隔离 API 数据进行浏览器检查，不调用真实模型、不重启用户正在运行的服务。


## 实施与验证结果

- 已按步骤完成共享外壳与统一会话历史。模式切换保留左右侧栏节点、搜索条件、文件树状态及两类会话草稿；设置往返也保留协同新任务草稿。
- 协同会话在历史和中间标题逐成员显示引擎图标，模型/角色通过图标说明提供；同引擎双成员显示两个图标。任务导航与原生会话编号隔离，普通聊天批量操作排除协同任务。
- 共享文件树使用所选任务目录，插入路径及选中文档文本进入协同要求；文件预览仍使用原有组件。任务终端复用现有终端组件并传入任务目录，不绑定隐藏的普通会话。
- 修复隐藏弹窗阻挡会话切换快捷键的情况，仅可见弹窗阻挡快捷键；协同页不响应普通聊天中断与并发窗格切换快捷键。
- TypeScript 项目检查及 Vite 生产构建通过（使用工作区已安装的二进制，无新增依赖；保留既有大包体积提示）。
- 前端定向测试 15 项通过，其中新增 4 项统一历史测试，覆盖成员去重展示、任一参与引擎筛选、相同引擎独立成员及混合日期/置顶分组；其余为现有搜索、分组和手机侧栏手势检查。
- 后端协同调度/API 的 21 项回归通过。未修改任务调度或成员权限机制。
- 使用生产资源和隔离 HTTP/WebSocket 数据进行浏览器检查，通过共享侧栏节点身份检查、同引擎双图标、搜索筛选、批量选择保护、文件树目录、插入路径及文件预览、任务控制、Alt 上下方向键跨类型切换、草稿保留、设置往返、创建与成员详情。终端连接消息确认使用任务目录且无普通聊天编号。
- 检查 320/390/768/1440px 布局、手机左右侧栏开关及浅色/深色截图，无横向溢出或浏览器运行异常。未做实体设备验收、真实引擎联跑或真实终端执行；未重启用户服务。全量旧测试的已知问题见第一版协同开发文档，本轮只运行上述定向检查。
- 本轮临时浏览器测试服务在退出时关闭；清理一次性测试脚本与日志后只提交本任务改动到本地，不推送。
