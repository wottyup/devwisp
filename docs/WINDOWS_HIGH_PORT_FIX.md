# Windows 网页端口避开系统排除范围

## 问题与分类

Windows 将 TCP 4093–4192 列为排除端口，固定使用 4173 的 Vite preview 在 `0.0.0.0` 绑定时返回 `EACCES`。本次是修复：恢复现有网页和 Android 连接能力，不增加新任务。

## 步骤

1. 用 Node 最小监听探针确认 4173 失败、26546 成功，并确认新端口未被其他进程使用。
2. 将 Vite 开发与预览、启动脚本、Windows 重启检查以及 Android 的默认地址统一为 26546；更新当前使用说明，保留历史记录。
3. 增加端口配置回归测试，运行相关测试和前端构建，验证 Vite 能在新端口监听。
4. 仅提交本次改动到本地仓库，不推送远端，也不擅自重启现有服务。
