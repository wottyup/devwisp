# Android 浏览器底部地址栏与工具区收起

## 需求与分类

用户希望参考 Edge 的控件位置，将原顶部网址编辑区移到底部浏览按钮上方；在网页左下角增加独立按钮，统一收起和展开这两排控件，让网页使用全部可用高度。继续使用 App 自己的主题和图标，收起整个浏览器到聊天页地球图标的既有功能继续保留。

本次为 Fix / PATCH：优化既有浏览器控件的位置与可见性，不改变浏览、收藏和页面恢复能力。目标 `0.132.1-dev.1`，Android `versionCode 483`。

## 实施步骤

1. 将页面结构改为网页内容、底部地址栏、底部浏览按钮；加载进度随底部控件一起显示，保留地址栏就地编辑、收藏、多页、下载及工具菜单。
2. 在网页左下角放置 44dp 触摸区域的小型悬浮按钮，显示收起/展开图标及中英文操作描述。两排控件收起使用 GONE，网页实际扩展高度，不额外保留按钮行；切换网页和加载失败时仍能展开。
3. 收起控件时结束未提交的地址编辑并关闭输入法，不提交网址、不重载网页。当前 Activity 内切换网页、收起/恢复整个浏览器时保留控件状态；明确关闭所有网页后恢复默认展开。返回键在控件已收起时先展开，再遵循原网页后退/浏览器收起逻辑。
4. 更新版本摘要和使用说明，运行 Android 构建及现有单元测试；核对 APK 包名、版本和签名，独占归档并核对更新接口选择、下载大小与哈希。记录手机验收边界，清理临时日志，只做本地提交，不推送，不提前安装或操作真实聊天。
