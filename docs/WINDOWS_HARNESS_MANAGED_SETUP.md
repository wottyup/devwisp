# Windows Harness 自动管理

分类：新增功能 / MINOR，目标版本 0.136.0-dev.1。

1. 增加当前 Python 环境的 SDK/运行组件检测，默认使用 SDK 附带的匹配运行组件。
2. 提供后台安装/修复任务及可轮询状态，固定依赖版本，不接收任意安装命令。
3. 增加实际 Harness 启动检查，检查结束关闭临时运行进程，不调用付费模型。
4. 高级设置允许指定外部原生可执行文件；通过 SDK 初始化确认兼容，不执行 shell 命令。
5. 设置页显示就绪状态和安装/检查按钮，保留现有 API 配置流程。
6. 检查 Python、前端构建与真实 SDK 启动，更新版本，仅本地提交。

安装修复作用于后端实际使用的 Python 环境。缺少 pip 或目录不可写时返回可操作提示，不切换系统 Python，也不重置现有会话与凭据。

完成：Windows 启动器首次缺少 SDK 或运行组件时自动准备；失败仍允许进入网页设置修复。真实 SDK 启动、自动模式保存、Python 与启动脚本语法检查和前端构建通过。未替换本机已有依赖以重复验证安装下载；当前后端需重启加载新增接口。
