# 协同任务第一版开发文档

## 目标与分类

在现有单聊之外增加独立的协同任务工作区，支持不同引擎的实现者与审查者交接完成同一个目标。单聊继续复用现有组件和行为，切换页面不停止后台任务。属于新功能 / MINOR，目标版本 `0.137.0-dev.1`。

## 第一版范围

- 共享导航提供聊天、协同两个入口；协同页包含任务列表、新建表单、成员状态、交接记录、补充要求和暂停/继续。
- 每个任务新建两个专属会话，选择 Codex、Claude Code 或 DeepSeek Harness，支持成员模型覆盖、工作目录与最多 1–5 轮实现/审查。
- 实现者负责修改和验证；审查者通过引擎权限配置只读检查，使用明确的审查结论标记。回合结束不等同于任务通过；缺少明确结果、引擎错误或人工交互时显示实际状态。
- 通过已有引擎接口启动回合、读取输出和中断。后端统一调度，SQLite 保存任务和事件，不向现有聊天注入模拟键盘输入。
- 暂停阻止新交接并中断本任务的活动回合；恢复继续当前阶段。服务重启恢复为暂停，保留历史并允许显式继续，不自动重放未知执行结果。
- 成员详情可以打开已有聊天页面。任务成员归属于协同任务，普通聊天列表不重复展示。
- 仅实现当前 Web 页面及其后端 API；Android 原生客户端暂不新增入口。

## 实施顺序

1. 检查现有引擎生命周期、事件通知、鉴权、导航和测试约定，确定接入位置。
2. 实现独立协同存储与调度模块，覆盖交接、审查判定、轮数限制、失败、暂停/继续、重启恢复及任务归属。
3. 接入已鉴权的任务 API 和现有引擎，统一任务会话创建、发送、读取、中断与只读审查配置；停止服务时释放调度资源。
4. 实现适配已有主题的协同工作区和页面切换，复用会话详情，处理加载、错误、空状态和移动布局。
5. 更新 README、版本与简要版本记录，运行针对性后端测试、前端检查和构建；检查窄屏与桌面视图。
6. 删除临时测试文件，关闭本轮启动的调试进程，检查差异并仅提交本任务文件到本地，不推送。

## 验证范围

- 使用假引擎运行真实调度与存储，验证双引擎交接、返工与通过，避免测试依赖真实模型费用或外部登录。
- 验证缺失结论、失败和人工交互不会误报通过；补充要求进入下一次派发上下文。
- 验证重复操作、暂停中的回合完成、恢复与重启不产生重复交接，不影响普通会话。
- 验证 API 鉴权、输入校验、任务详情与成员会话归属。
- 运行 `pnpm --filter devwisp build`、现有前端测试及相关后端测试；页面使用隔离的测试服务和假引擎数据检查，不重启现有服务或操作用户真实会话。

## 限制

这一版是有界的实现/审查流程，不包含自主拆任务、成员互发工具、多工作树合并或跨主机调度。引擎实际可用性以本机安装和配置为准。自动化验证使用假引擎，真实模型端到端结果须如实另行说明。
