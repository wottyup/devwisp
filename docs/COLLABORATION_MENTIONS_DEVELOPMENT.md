# 群聊 @ 点名回复

## 需求与分类

群聊中可以直接点名某位成员，只让该成员回复；保留共享单聊输入框、不增加模式或必选设置。未点名保持全员顺序回复。新增此前无法进行的定向群消息，分类 New Features / MINOR，目标 0.142.0-dev.1。本地提交，不推送；不调用真实模型做测试。

## 实施步骤

1. 增加消息开头的 @ 成员语法与输入建议：输入 @ 出现成员列表，点击或方向键/Enter 选中，Escape 关闭；手机可点击。使用完整成员名称区分同引擎多成员，唯一引擎允许 @Codex/@Claude/@DeepSeek 简写，歧义提示选择具体成员。支持连续点名与 @所有人。
2. 在提交/定时/后台翻译/编辑时由后台解析原始用户文字，保存目标成员 ID；不从附件、引用历史或模型回复中推断目标。翻译与排队保留目标，成员移除后保留队列并提示，不自动转发其他成员。
3. 本轮仅调度目标成员，提示明确本轮回复者；群内仍可见该消息及回复。运行中的点名消息排为独立轮次，即使 Ctrl+Enter 也不误插入未点名的当前成员，普通群消息的插队及单聊保持原逻辑。
4. 验证点名单个/多个、重复引擎、全员、未知及移除成员、翻译/编辑/定时、忙碌插队隔离；验证实际输入框的键盘/点击/手机交互并完成类型检查和构建。
5. 更新简要版本历史和说明并本地提交。本轮遵照用户要求不推送、不部署，不重启运行中的服务；清理临时验证文件。

## 完成与验证

- 已在原共享输入框加入成员建议，支持点名一个或多个成员、唯一引擎简称以及全员。选中候选只插入名称，不提交消息；输入法确认保持原有行为。修正 Escape 后选区事件重新打开候选以及异步移动光标干扰后续输入的问题。
- 后台按原始用户文字解析并冻结成员 ID。群历史保留消息，仅指定成员参与本轮；忙碌点名排为单独一轮。翻译、排队编辑和定时消息保留目标；成员退出时保持待发送并提示重新选择，同引擎新成员加入也不会改变原目标。
