# 协同会话重命名

## 需求与分类

补齐左侧协同记录的右键重命名入口，复用单聊的名称编辑弹窗，手机长按同样可用。空群经用户命名后，第一条消息不能覆盖名称；多个默认同名群按各自编号独立保存。该改动修复已有聊天管理在协同记录上的缺失，属于 Fix / PATCH，版本 `0.139.3-dev.1`。

## 实施步骤

1. 协同服务增加按会话编号持久化名称的方法和受配对保护的接口，名称规则沿用单聊（非空、最长 72 字符、合并空白）。使用现有会话锁，运行中的群也能改名，不能更改成员、发送状态及请求幂等信息。
2. 群聊侧栏支持右键/长按；仅展示适用的重命名菜单，复用现有弹窗，保存时按会话类型调用对应接口。刷新侧栏和中央标题，普通单聊继续走原生重命名接口。
3. 增加名称持久化、无效输入、认证、同名群隔离、首次发言及运行中重命名不被覆盖的针对性验证；完成前端类型检查、生产构建和隔离浏览器流程验证，不调用真实模型。
4. 更新简要版本历史并本地提交，不推送。构建先放入独立临时目录，后台在模型回合空闲后更新并校验新接口，再发布前端构建，避免再次出现前后端版本不一致。发布任务完成后清理临时构建和验证脚本。

## 验证结果

- 协同服务及 API 共 56 项测试通过，新增验证同名群独立保存、持久化读取、认证与输入校验、旧任务改名、空群手动名称跨消息/重启保持、运行中改名不更改回合或发送次数。
- TypeScript 检查与隔离目录生产构建通过，构建仅有既存的大包提示。
- 模拟 API 的完整浏览器验证通过：桌面右键改名、另一个同名群保持独立、中央标题同步、刷新后名称保留、普通单聊继续使用原生接口、390px 手机长按、保存失败后保留草稿并成功重试，无页面脚本错误。验证浏览器和临时 HTTP 服务均已关闭，临时验证脚本在提交前删除。
- 没有调用真实模型。前端尚未发布到运行服务，需等当前模型回合空闲、后台新接口通过校验后再切换前端入口；独立临时构建由激活任务在结束时清理。
