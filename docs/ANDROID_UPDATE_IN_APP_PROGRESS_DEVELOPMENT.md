# Android 更新下载在 App 内显示进度

## 需求与分类

用户希望“检查更新 → 下载更新”的下载进度直接显示在 App 内，不再依赖系统下载通知。保持现有局域网更新、后台下载、SHA-256 校验和系统安装流程，优化进度可见性和取消操作，属于 Fix / PATCH。目标版本 `0.131.1-dev.1`，Android `versionCode 480`。

## 实施步骤

1. 保留 DownloadManager 负责下载与后台任务，仅对 App 更新请求使用隐藏通知模式，并声明所需的普通权限；网页文件下载沿用既有行为。
2. 添加与现有主题一致的下载弹窗：横向进度条、百分比、已下载/总大小、等待网络与校验状态，支持取消下载和收起。收起不取消任务，重新点击“检查更新”优先恢复当前任务进度，不重复下载。
3. 轮询现有任务的字节数、总大小与暂停原因；清单大小作为系统尚未报告总大小时的备用值。按任务 ID 隔离取消、清理和异步校验结果，避免旧回调影响新任务；前后台切换及重启 App 后继续读取持久化的下载任务。
4. 完成下载后保留 SHA-256 校验与安装确认；失败清理过期状态，取消仅移除当前更新任务。补齐英文文案、更新说明和发布版本。
5. 构建 Android APK 并执行现有单元测试，核对版本、包名、签名和隐藏通知权限；按规范文件名独占归档至 artifacts，验证更新清单选择。仅本地提交，不推送；不提前安装、不操作真实聊天、不重启服务，清理本次临时资源。
